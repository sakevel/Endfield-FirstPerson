# 第一人称 (First Person)

为《明日方舟：终末地》提供第一人称视角切换功能，支持真实头部眼位绑定、头颈动作跟随、平滑与迈步转身，以及角色专属趣味视野效果。

## 操作方式

| 操作 | 默认键位 / 入口 | 说明 |
|---|---|---|
| **切换视角** | `Ctrl+F5` | 切换第一人称与第三人称（可在游戏「设置 → 按键绑定」修改） |
| **参数调节** | `ESC` → 模组菜单 → 第一人称 | 实时调整视野（FOV）、灵敏度、眼高及跟随选项 |

> 过场动画、剧情对话或打开全屏菜单时，相机会自动交还游戏原生控制。

## 功能特性

- **自由视角控制**：支持 40°~120° 垂直视野（FOV）自由调节与独立视角灵敏度倍率。
- **角色身体可见**：低头时可见自身躯干与四肢，第一人称下自动隐藏头部模型，避免穿模遮挡视线。
- **头颈联动与真实眼位**：支持镜头绑定到真实头部位置，随角色脖子与头部关节沿弧线运动，还原真实第一人称视野。
- **动态姿态跟随**：可开启视角跟随动作起伏、前后晃动与侧倾；视角偏离角色朝向时自动平滑转身，支持触发游戏原生迈步转身动作。
- **角色专属视野**：
  - **汤汤**：左侧视野圆弧眼罩遮挡效果
  - **管理员**：抑制器周期性地形扫描波纹与光带效果
  - **大潘**：墨镜滤镜暗化效果
