# 第一人称 (First Person)

为《明日方舟：终末地》提供沉浸式第一人称视角体验。支持自由视角缩放、动作姿态跟随、平滑转身以及角色专属的趣味视野效果。

## 功能特性

- **自由视角控制**：默认快捷键 `Ctrl+F5` 快速切换第一人称/第三人称视角；支持 40°~120° 垂直视野（FOV）调节与独立灵敏度倍率。
- **角色身体可见**：低头时可见自身躯干与四肢，仅在第一人称视角下隐藏头部与头发模型，避免遮挡视线。
- **动态姿态跟随**：可独立开启头部前后/左右位移跟随、动作起伏跟随与侧倾效果；视线偏离角色朝向超过 90° 时自动触发平滑转身。
- **专属趣味视野**：
  - **汤汤**：左侧视野圆弧渐变眼罩遮挡效果。
  - **管理员**：抑制器周期性扫描波纹与光带效果。
  - **大潘**：墨镜滤镜暗化效果。
- **原生设置与菜单融合**：依赖 `keybinds` 模组，快捷键可在游戏原生「设置 → 按键绑定」中自由修改；所有参数均可在模组配置菜单中即时热应用。

## 玩家使用指南

1. 安装本模组至 `<游戏根目录>\ZML\mods\first-person`。
2. 确保已同时安装并启用 `keybinds` 模组。
3. 进入游戏后按 `Ctrl+F5` 即可切换第一人称视角。
4. 在模组配置页面可微调眼高、视点前移、平滑度与角色专属视野开关。
