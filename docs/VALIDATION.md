# 测试与功能验证指南

本文档介绍 Endfield-FirstPerson（第一人称模组）的自动化测试套件与实机功能验证方法。

---

## 1. 自动化测试套件

构建完成后可运行 CTest 自动化测试：

```powershell
ctest --test-dir build -C Release --output-on-failure
```

### 测试用例说明

- **Contract (`tests/contract.cpp`)**：
  - 验证 `FirstPerson.dll` 导出标准 `ZML_PluginV1` 符号及 ABI1 契约。
  - 验证插件在 `BattleActionCtrl` 与 `LevelCameraCtrl` 中的注入锚点唯一性与原子替换。
  - 验证异常输入、重复加载及边界条件下的防重入保护。

- **PackageManifest (`tests/package.py`)**：
  - 验证发布包文件列表完整性与白名单规则。
  - 验证 `mod.ini` 与 `config.ini` 的配置项声明及类型边界。
  - 验证 256×256 图标格式规范。

- **BehaviorTests (`tests/behavior.py` / `tests/behavior.lua`)**：
  - 验证相机状态机的视角俯仰限制、跨圈偏航角规约。
  - 验证可配置转身阈值、跨 ±180°、原生异步转身完成与配置兼容。
  - 验证模组配置项的热重载机制与容错回滚。

- **NativeAdapterTests (`tests/native.py` / `tests/native_scenarios.lua`)**：
  - 验证虚拟相机租约申请与释放生命周期。
  - 验证头部模型隐藏与身体可见性切换逻辑。
  - 验证专属视野效果的资源加载与安全注销。

---

## 2. 实机功能验证清单

在游戏客户端中依次验证以下核心功能：

1. **基础视角切换**：
   - 按下快捷键 `Ctrl+F5`，视角在第三人称与第一人称之间平滑切换。
   - 打开游戏原生「设置 → 按键绑定」，确认第一人称动作正常呈现并支持重新改键。

2. **视点与运动跟随**：
   - 调整视野大小（40°~120°），视角范围即时生效。
   - 慢速与快速移动角色，确认头部与身体跟随自然；旋转视角时，确认角色超过配置阈值时自动平滑转身。
   - 俯仰视线，确认眼高稳定，低头可观察到自身躯干与四肢。

3. **角色专属视野**：
   - 切换为主控角色「汤汤」，观察左侧圆弧眼罩效果。
   - 切换为主控角色「管理员」，观察抑制器周期性扫描波纹与光带效果。
   - 切换为主控角色「大潘」，观察墨镜暗化效果。

4. **状态恢复**：
   - 打开背包、地图或进入对话剧情，确认相机控制权自动交还游戏原生逻辑，无画面撕裂或卡死。
   - 再次按下快捷键关闭第一人称，确认完全恢复原生第三人称相机。
